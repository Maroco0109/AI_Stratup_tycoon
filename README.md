# AI 스타트업 타이쿤 (Chat-Driven Tycoon) – README

> **한 줄 소개**
> 채팅만으로 제품 기획→개발→런칭→위기대응을 진행하는 게임입니다. 한국어에 강한 `yanolja/YanoljaNEXT-EEVE-10.8B`(또는 Instruct 변형)을 **Ollama + GGUF**로 로컬에서 띄우고, **Streamlit**으로 UI를 구성합니다.

---

## 1) 프로젝트 개요

* **목표**: “채팅이 곧 게임” 스타트업 경영 시뮬레이터를 구현합니다. 모델은 EEVE 10.8B 계열을 사용합니다. EEVE는 한국어 어휘를 확장하고 한국어 데이터로 튜닝된, SOLAR-10.7B 기반 한국어 특화 모델입니다.
* **메인 루프(전부 채팅)**:

  * CTO/PM/고객/투자자 페르소나(NPC)를 LLM이 수행 → 플레이어(CEO)는 채팅으로 의사결정
  * 라운드마다 지표(활성/잔존/수익) 요약 → 7일차 종료 후 최종 결과 리포트

---

## 2) 구조(로컬 전용)

```
Streamlit (Python, 로컬 앱)
   ├─ 채팅 UI/상태 패널/지표 카드
   └─ 로컬 HTTP 호출 → Ollama (localhost:11434)
        └─ EEVE(GGUF) 로드 및 추론
```

* **Streamlit**: 파이썬만으로 즉시 UI 구현 가능한 프레임워크. 설치/실행이 단순해 로컬 프로토타입에 적합합니다.
* **Ollama + Modelfile**: GGUF 모델을 손쉽게 로컬에서 생성/실행하고, 시스템 메시지·파라미터를 Modelfile로 관리합니다.
* **GGUF**: llama.cpp 생태계의 고속 로딩/추론을 위한 바이너리 포맷입니다(이 프로젝트에서는 EEVE GGUF 사용).

---

## 3) 사용 기술 스택

* **언어/프레임워크**: Python 3.10+, **Streamlit**
* **LLM 서빙(로컬)**: **Ollama** + **GGUF**(EEVE 10.8B / EEVE-Instruct 10.8B 권장)
* **모델**: `yanolja/YanoljaNEXT-EEVE-10.8B` 계열(한국어 어휘 확장·튜닝)

---

## 4) 게임 룰북 (간단/7일 진행)

### 공통 규칙

* 모든 상호작용은 **한국어 채팅**으로 진행(존댓말 기본).
* NPC 역할: **CTO / PM / 고객 / 투자자**.
* 출력 형식(권장):

  * `역할: 한두 문단` (간결·구체)
  * 하루가 끝날 때 `요약: …`, `지표: 활성/잔존/수익`
* 금지: 개인정보 요구, 법률·의료·투자 확답 등 민감 조언.

### 진행 규칙(7일차까지)

* **Day 1 – 회사/제품 정의**: 산업·타깃·수익모델 선택 → LLM이 초기 PRD/핵심가설 제시.
* **Day 2 – 스프린트 계획**: CTO/PM과 백로그 우선순위·리스크 합의.
* **Day 3 – 고객 피드백**: 가설 검증용 인터뷰/리뷰(LLM-고객) → 개선 액션 확정.
* **Day 4 – 장애 대응**: 성능/프라이버시 이슈 중 랜덤 이벤트 → 대응책 채팅으로 결정.
* **Day 5 – 미니 런칭**: 간이 릴리즈/알파테스트 설정 → 반응 수집.
* **Day 6 – 투자자 미팅**: 트랙션/코호트/예산 질의응답(LLM-투자자).
* **Day 7 – 회고/최종 리포트**: 지표 요약, 리스크 레이더, 다음 분기 제안 출력.

> **지표 계산(간이)**: 선택지에 따라 가중치 테이블로 `활성/잔존/수익` 점수(0~100)를 갱신 → 일일 요약에 표시 → 7일차 집계.

## 7) Streamlit 페이지 시연 순서

1. **회사 만들기**: 산업/타깃/수익모델 입력 → LLM이 `PRD 요약` 제시
2. **스프린트 합의(CTO/PM 채팅)**: 백로그/리스크 정리 → `Day 2 요약 & 지표`
3. **고객 라운드**: 불만/요청 수집 → 개선안 선택 → `Day 3 요약 & 지표`
4. **장애 대응**: 랜덤 이슈 등장 → 대응책 채팅 → `Day 4 요약 & 지표`
5. **미니 런칭**: 알파테스트 후 반응 취합 → `Day 5 요약 & 지표`
6. **투자자 미팅**: 질문 공세 대응 → `Day 6 요약 & 지표`
7. **최종 리포트**: 7일 누적 지표/리스크 레이더/다음 스텝 출력(다운로드 가능)
